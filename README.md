# -# STM32F103C8T6 九轴姿态测量系统 —— 项目简介

## 一、项目概述

本项目是一套运行在 **STM32F103C8T6** 上的嵌入式姿态测量固件，通过 **MPU6050** 六轴惯性传感器与 **HMC5883L** 三轴磁力计构建九轴传感器系统，采用**互补滤波算法**实时解算载体的横滚角（Roll）、俯仰角（Pitch）与航向角（Yaw），并通过 OLED 本地显示、USART1 串口对外输出。

固件基于 **STM32F10x 标准外设库（StdPeriph Lib）** 开发，**寄存器级直接操作 I2C 外设**，不使用 HAL 库与硬件抽象层，代码体积小、执行效率高，适合作为嵌入式姿态测量的学习与二次开发基础。

| 项目属性 | 说明 |
|---|---|
| 主控芯片 | STM32F103C8T6（Cortex-M3，72MHz，64KB Flash / 20KB SRAM） |
| 开发工具 | Keil MDK-ARM 5.x |
| 依赖库 | STM32F10x Standard Peripheral Library V3.5.0 |
| 编程语言 | C（C99） |
| 代码规模 | 自研业务代码约 1517 行，含厂商库共 14574 行 |
| 更新频率 | 姿态解算 100Hz，串口输出 20Hz |

## 三、核心功能

### 3.1 传感器数据采集

**MPU6050** 采用一次性突发读取 14 字节的方式，单次事务即完成加速度（6 字节）、温度（2 字节）、角速度（6 字节）的采集，避免多次 I2C 事务带来的时间抖动与轴间不同步。

关键配置：

| 寄存器 | 配置值 | 含义 |
|---|---|---|
| `PWR_MGMT_1` | `0x01` | 唤醒器件，选择 X 轴陀螺 PLL 作为时钟源 |
| `SMPLRT_DIV` | `0x09` | 采样率 100Hz（1kHz / 10） |
| `CONFIG` | `0x03` | 数字低通滤波，带宽 44Hz（陀螺）/ 42Hz（加速度） |
| `GYRO_CONFIG` | `0x18` | 陀螺满量程 ±2000 dps，灵敏度 16.4 LSB/(°/s) |
| `ACCEL_CONFIG` | `0x18` | 加速度满量程 ±16g，灵敏度 2048 LSB/g |

**HMC5883L** 从 `0x03` 起始连续读取 6 字节。需特别注意该芯片的数据寄存器排布为 **X_H, X_L, Z_H, Z_L, Y_H, Y_L**，Z 轴前置于 Y 轴，且高字节在前，解析时不可按常规 XYZ 顺序处理。

关键配置：

| 寄存器 | 配置值 | 含义 |
|---|---|---|
| `CRA` (0x00) | `0x78` | 8 次平均 + 75Hz 输出速率 + 正常测量 |
| `CRB` (0x01) | `0x20` | 增益 1090 LSB/Gauss，量程 ±1.3 Ga |
| `Mode` (0x02) | `0x00` | **连续测量模式** |

### 3.2 姿态解算算法

采用**互补滤波**融合三类传感器数据，兼顾动态响应与长期稳定性：

**第一步：加速度计解算静态倾角**

$$\text{Pitch} = \arctan\frac{-A_x}{\sqrt{A_y^2 + A_z^2}}, \quad \text{Roll} = \arctan\frac{A_y}{A_z}$$

加速度计在静止或低速运动时能准确感知重力方向，提供无漂移的绝对倾角参考，但对线性加速度与振动敏感。

**第二步：磁力计倾角补偿求航向**

磁场矢量需由机体坐标系旋转至水平面后方可求航向，否则倾斜状态下航向会随姿态变化：

```c
BX =  Hx·cos(pitch) + Hy·sin(roll)·sin(pitch) + Hz·cos(roll)·sin(pitch)
BY =  Hy·cos(roll)  − Hz·sin(roll)
Yaw_mag = atan2(BY, BX)
```

**第三步：互补滤波融合**

$$\theta = \alpha\,(\theta_{prev} + \omega \cdot \Delta t) + (1-\alpha)\,\theta_{acc}$$

其中滤波系数 α = 0.98，即以 98% 权重信任陀螺积分（短期精度高），2% 权重用于加速度计与磁力计的长期修正，从而抑制陀螺零偏导致的积分漂移。

| 参数 | 取值 | 说明 |
|---|---|---|
| `MPU6050_DT` | 0.01 | 采样周期 10ms，与 TIM2 中断周期严格对齐 |
| `COMP_FILTER_ALPHA` | 0.98 | 互补滤波系数 |
| 陀螺零偏 | 200 次采样均值 | 静止校准，积分前扣除 |

### 3.3 陀螺零偏校准

MEMS 陀螺普遍存在零偏，若直接积分会导致角度随时间**单方向持续漂移**（以 1°/s 零偏计，30 秒即累积 30° 误差）。

固件在启动阶段调用 `MPU6050_CalibrateGyro()`，在器件静止状态下采样 200 次求均值作为三轴零偏，姿态解算时先行扣除，从根本上消除静态漂移。

> 该函数要求调用时器件**完全静止**，固件已在串口输出提示信息引导操作。

### 3.4 数据输出协议

串口按 **NMEA 风格**格式输出，便于上位机与飞控软件解析：

```
$Roll,Pitch,Yaw*CS\r\n
```

| 字段 | 类型 | 范围 | 说明 |
|---|---|---|---|
| `Roll` | float | ±180.00 | 横滚角，单位度，2 位小数 |
| `Pitch` | float | ±90.00 | 俯仰角，单位度，2 位小数 |
| `Yaw` | float | ±180.00 | 航向角，单位度，2 位小数 |
| `CS` | hex | 00–FF | 校验和：`$` 与 `*` 之间所有字符的逐字节异或 |

**示例**：`$1.25,-12.34,179.99*0E`

### 3.5 人机交互

- **OLED 显示**：四行分别显示 Pitch、Roll、Yaw 与数据包计数，角度以 `±XX.X` 格式呈现，支持负数与整数位对齐
- **板载 LED**：1Hz 心跳闪烁，指示系统运行状态
- **上电自检**：启动时校验两颗传感器通信，并在串口打印器件 ID，异常时给出接线提示

## 五、运行流程

```
上电复位
   │
   ├─ SystemClock_Config()     配置 HSE 8MHz × 9 = 72MHz
   │
   ├─ 外设初始化
   │    ├─ LED_Init / OLED_Init
   │    ├─ MPU6050_Init()      ★ 含 I2C2 总线初始化（PB6/PB7，400kHz）
   │    ├─ HMC5883_Init()        复用总线，仅配置器件寄存器
   │    ├─ NVIC_Init2()         先于定时器启动使能中断
   │    ├─ Timer_Init()         TIM2 启动，10ms 周期
   │    └─ Serial_Init()        USART1 9600 8N1
   │
   ├─ 上电自检：读取并打印两颗器件 ID
   │
   ├─ 陀螺零偏校准（需静止）
   │
   └─ 主循环 while(1)
        ├─ imu_update_flag 置位 → UpdataAngal() 解算 + OLED 刷新   100Hz
        ├─ usart_send_flag 置位 → 打包发送数据帧                    20Hz
        └─ 无待处理任务 → 关中断检查标志后进入 __WFI() 低功耗待机
```

**中断驱动 + 低功耗待机**的设计使 CPU 在无事可做时进入睡眠，由 TIM2 中断唤醒，在保证实时性的同时降低功耗。

## 六、技术要点

### 6.1 硬件 I2C 的完整状态机实现

固件直接操作 STM32 的 I2C 外设寄存器，通过 `I2C_CheckEvent()` 逐事件驱动状态流转（EV5 → EV6 → EV8 → EV7），而非依赖库函数封装。读取时序严格遵循规范：

- 写阶段发送寄存器地址后，以**重复起始条件**（Repeated START）切换方向，中间不产生 STOP
- 最后一字节**先关闭 ACK 再产生 STOP**，否则会多读取一个字节
- 传输结束后恢复 ACK 使能，供后续事务使用

### 6.2 总线超时与故障恢复

I2C 总线在从机掉电或复位时可能被持续拉低 SDA，导致主机永远等不到事件标志而死锁。固件对此做了两层防护：

1. **超时保护**：所有事件等待均设超时计数，超时即返回失败码，不再无限等待
2. **总线恢复**：关闭 I2C 外设，将引脚临时切为 GPIO 开漏模式，手动产生 **9 个 SCL 时钟**打空从机移位寄存器，随后补发 STOP 条件并恢复外设

读取失败时，驱动保持上一次的有效数据不变，避免将 0 值当作真实测量送入姿态解算。

### 6.3 中断与主循环的并发安全

主循环与定时器中断通过 `volatile` 标志通信。低功耗待机采用**关中断原子检查**，杜绝"标志已消费却仍进入睡眠"的竞态：

```c
__disable_irq();
if (!imu_update_flag && !usart_send_flag)
{
    __enable_irq();
    __WFI();          /* 确认无事可做才休眠 */
}
else
{
    __enable_irq();   /* 有任务，直接继续执行 */
}
```

### 6.4 单精度浮点优化

STM32F103 无硬件浮点单元，双精度运算需软件模拟，开销显著。固件统一使用 `atan2f` / `sqrtf` / `sinf` / `cosf` 等**单精度数学函数**替代对应的双精度版本，在满足精度要求的前提下大幅降低运算耗时。

### 6.5 传感器通信自检

启动阶段主动读取并校验器件 ID，将硬件问题暴露在最早时刻，而非等到姿态数据异常才排查：

```
MPU6050 ID: 0x68 (expect 0x68)
HMC5883L ID: 0x48 (expect 0x48)
Calibrating gyro, keep device still...
Calibration done.
```

## 七、编译与使用

### 7.1 编译

1. 使用 **Keil MDK-ARM 5.x** 打开工程文件 `2-1.uvprojx`
2. 确认已在 `Options for Target → C/C++ → Include Paths` 中包含以下目录：
   ```
   .\Dlay;.\Libraries;.\start;.\User;.\heardware
   ```
3. 确认预定义宏包含 `STM32F10X_MD` 与 `USE_STDPERIPH_DRIVER`
4. 编译后通过 ST-Link 下载至目标板

### 7.2 使用步骤

1. 将器件**水平静止放置**，上电
2. 观察串口输出，确认两颗传感器 ID 校验通过
3. 等待陀螺校准完成（约 1 秒，期间保持静止）
4. 串口每 50ms 输出一帧姿态数据，OLED 同步刷新显示

### 7.3 数据接收

任何支持串口的终端工具均可接收，波特率 **9600**，推荐使用支持 NMEA 协议解析的上位机以获得可视化姿态展示。

## 九、已知约束

1. **陀螺校准需静止** —— 校准期间若器件晃动，零偏计算失准会引入新的漂移
2. **量程与灵敏度须同步修改** —— 若调整 `GYRO_CONFIG` 量程，必须同步修改 `MPU6050_GYRO_SENS_2000DPS`，两者不匹配会导致角度整体缩放错误
3. **磁力计轴系对齐** —— 若 HMC5883L 与 MPU6050 的物理安装方向不一致，需在解算前做坐标变换
4. **SysTick 独占** —— `Delay` 模块独占 SysTick，不应再将其用于其他计时用途，否则时间基准会冲突
5. **万向锁** —— 俯仰角接近 ±90° 时姿态解算退化，属欧拉角表示法的固有限制
